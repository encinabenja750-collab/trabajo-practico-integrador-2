
# Trabajo Práctico Integrador N° II - Frontend en React

Este proyecto es el frontend desarrollado en React con Vite y Tailwind CSS para el Sistema de Gestión de Blog Personal.

## Repositorio del Backend Utilizado
* **Repositorio del Backend (TPI I):** https://github.com/encinabenja750-collab/trabajo-practico-integrador-1.git

## Cómo levantar el proyecto localmente

1. Clonar el repositorio:
   
   git clone https://github.com/encinabenja750-collab/trabajo-practico-integrador-2.git
   
2. Instalar las dependencias de Node:
   npm install

3. Crear un archivo `.env` en la raíz con la URL del backend:

   VITE_API_URL=http://localhost:3000

4. Iniciar el servidor de desarrollo:
   
   npm run dev
